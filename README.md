# PR 多版本交付导出（pr-Multi-version-export）

一个 Premiere Pro CEP 扩展面板：批量勾选序列，按「可自由搭配的版本列表」一键导出，专为「海外人名条」竖版短视频的交付流程设计。

## 它能做什么

针对你选中的序列，按配置好的版本列表依次跑完所有渲染。每个版本独立配置：

| 配置项 | 说明 |
|---|---|
| 启用 | 勾选才参与导出，支持单独导出某个版本 |
| 版本名 | 任意，如「成片」「无字幕」「无音乐无字幕」 |
| 导出预设 | 下拉选（自动扫描 AME 预设目录的 `.epr`），也可手动输入 |
| 音轨模式 | 不静音（全轨保留）/ 静音非保留轨（去音乐） |
| 保留音轨 | 去音乐版本勾选要保留的人声轨（如 A1、A2） |
| 输出目录 | 每版本独立填，可「浏览…」选择 |

内置三个默认版本：**成片**、**无字幕**、**无音乐无字幕**。点「＋添加版本」可自定义。

## 交付结构自动填充（核心便利功能）

你的交付文件夹是固定模板（数字前缀命名），选中根目录后一键填充各版本路径：

```
000交付/
  00成片/                    → 版本「成片」
  1.有音乐无字幕版本/          → 版本「无字幕」
  2.无音乐无字幕无bgm/         → 版本「无音乐无字幕」
  3.字幕文件/                 → 字幕独立目录
  4.工程截图/                 → 自动忽略
```

面板「交付结构」组里选根目录 → 点「自动填充各版本路径」，脚本扫描子文件夹，按数字前缀 + 名称关键词双保险匹配，把各版本输出目录和字幕目录一次填好。**只填充，不自动导出**，确认后再点导出。

## 字幕 srt 自动归位

字幕从版本卡片里独立出来，单独一组：

- 一个「导出字幕 srt」开关 + 一个独立的字幕输出目录（默认对应 `3.字幕文件`）。
- 原理：无字幕版预设勾选「创建 Sidecar 字幕」，导出时白捡一个 srt。
- 脚本把 `1.mp4.srt` 改名成 `1.srt`，再移动到你指定的字幕目录。

## 交付清单（可选）

导出完成后自动生成 CSV 核对表（列：序列 / 版本 / 状态 / 输出文件 / 大小 / 时长），落在首个版本输出目录，文件名 `交付清单_YYYY-MM-DD_HH-MM.csv`。可在「交付结构」组里开关是否生成。

## 在别的电脑上安装

> 这是未签名的本地扩展，装一次即可。之后每次进 PR 直接在「窗口 → 扩展 → 多版本导出」打开。

**第一步：开启开发者模式（每台新电脑只需做一次）**

1. `Win + R` 输入 `regedit` 回车，打开注册表编辑器。
2. 定位到 `HKEY_CURRENT_USER\Software\Adobe\CSXS.x`（`.x` 可能是 `.5` 到 `.12`，看你 PR 版本；不确定就把存在的都改一遍）。
3. 若没有 `CSXS.x` 这个键，右键 `Adobe` → 新建 → 项，命名为 `CSXS.x`。
4. 在右侧空白处右键 → 新建 → **字符串值**，名字填 `PlayerDebugMode`，值填 `1`。
5. 关闭注册表编辑器。这一步让 PR 允许加载未签名扩展。

**第二步：复制扩展文件夹**

1. 完全关闭 Premiere Pro。
2. 把 `com.delivery.multiexport` 文件夹复制到：
   ```
   C:\Users\你的用户名\AppData\Roaming\Adobe\CEP\extensions\
   ```
   （`AppData` 是隐藏文件夹，资源管理器地址栏直接粘贴 `%APPDATA%\Adobe\CEP\extensions` 回车即可到达。）

**第三步：在 PR 里打开**

1. 启动 Premiere Pro。
2. 菜单「窗口」→「扩展」→「多版本导出」。
3. 面板出现在右侧，拖到顺手的位置。

> 建议在 PR 里先建好导出预设（有字幕版 / 无字幕版），预设放在 AME 的预设目录（`文档\Adobe\Adobe Media Encoder\<版本>\Presets\`），这样面板下拉能直接扫到。无字幕版预设需额外勾选「创建 Sidecar 字幕」，用于白捡 srt。

## 使用

1. **选序列**：勾选要导出的序列（可多选）；纯数字命名的序列（如 `1`、`12`）会自动勾上。
2. **配交付结构**（可选）：选根目录 → 自动填充各版本路径。
3. **配版本**：每个版本卡片里选预设、定音轨模式、填目录（或点「浏览…」）。
   - 成片类：音轨模式选「不静音」。
   - 去音乐类：选「静音非保留轨」，并在下方勾选要保留的人声轨。
4. **配字幕**（可选）：勾「导出字幕 srt」，填字幕输出目录。
5. 点「一键导出」。顶部有进度条（百分比 / 当前状态 / 已用时间 / 预计剩余），可「停止」。

所有配置（版本 / 预设 / 音轨 / 目录 / 交付根目录 / 字幕开关）会自动记住，重开面板不丢。

## 产物

每个版本各自输出到独立目录，文件名保持序列名：

```
版本A的目录\序列名.mp4
版本B的目录\序列名.mp4
```

若多个版本填了同一个目录，自动给文件名加 `_版本名` 后缀避免覆盖。输出后缀（`.mp4`/`.mov`/`.mxf`…）由各版本所选预设的 `ExporterFileType` 自动推断。

## 关键实现说明

- **静音 API**：`Track.setMute(1/0)` 是 Premiere 原生 ExtendScript API（成功返回 0），无第三方依赖。
- **导出 API**：`Sequence.exportAsMediaDirect(outputPath, presetPath, exportType)`，提交到 AME 渲染队列。
- **目录浏览**：改用 Windows 现代文件对话框（`IFileDialog` 的 `SetFolder`），精确定位上次选择的目录；绕开老式 `FolderBrowserDialog`「起始目录只第一次生效」的 Win7 老 bug。
- **防竞态**：每个版本串行导出，等输出文件完整落地（大小稳定 2 秒）再做下一个；「去音乐」版本导出前静音、导出后立即恢复。
- **容错**：导出中途出错或停止，自动恢复所有音频轨静音。
- **配置持久化**：版本列表等存 `localStorage`。
- **停止语义**：停止是「软停止」，只能让当前这条跑完后不再开始下一条，无法中断 AME 里正在渲染的任务（Premiere 脚本能力限制）。

## 目录结构

```
com.delivery.multiexport/
├── CSXS/manifest.xml        # 扩展清单（PPRO 14.0 / CSXS 7.0）
├── index.html               # 面板 UI
├── js/CSInterface.js        # CEP 桥接库
├── js/main.js               # 编排逻辑（版本列表、批量、进度、停止、目录浏览、字幕归位、清单）
└── jsx/
    ├── host.jsx             # 宿主脚本（PR 内执行：序列/音轨/导出）
    └── folderpicker.ps1     # 目录选择对话框（IFileDialog 封装）
```

## 环境

- 目标宿主：Premiere Pro 2025（PPRO 14.0+）
- 面板运行时：CEP 7.0，需 `--enable-nodejs`
- 本机已开 CEP 调试模式（`PlayerDebugMode=1`）
