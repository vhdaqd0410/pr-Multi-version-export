# PR 多版本交付导出（pr-Multi-version-export）

一个 Premiere Pro CEP 扩展面板：批量勾选序列，按「可自由搭配的版本列表」一键导出，专为「海外人名条」竖版短视频的交付流程设计。

## 它能做什么

针对一个序列，按你配置好的版本列表依次跑完所有渲染。每个版本独立配置：

| 配置项 | 说明 |
|---|---|
| 启用 | 勾选才参与导出，支持单独导出某个版本 |
| 版本名 | 任意，如「成片」「无音乐有字幕」 |
| 导出预设 | 下拉选（自动扫描 AME 预设目录的 `.epr`） |
| 音轨模式 | 不静音（全轨道）/ 静音非保留轨（去音乐） |
| 输出目录 | 独立填，可「浏览…」选择 |

默认给三个初始版本：**成片**（有字幕）、**无字幕**、**无音乐无字幕**。随时点「＋添加版本」自定义，比如「无音乐但有字幕」= 有字幕预设 + 去音乐模式。

字幕 srt 文件保留手动导出（全选序列 → 文件 → 导出 → 字幕），因为 Premiere 的 ExtendScript 对字幕轨导出支持很弱，强做自动化只会时灵时不灵。

## 在别的电脑上安装

> 这是未签名的本地扩展，装一次即可，之后每次进 PR 直接在「窗口 → 扩展」里打开。

**第一步：开调试模式（每台新电脑只需做一次）**

1. 按 `Win + R`，输入 `regedit` 回车，打开注册表编辑器。
2. 定位到 `HKEY_CURRENT_USER\Software\Adobe\CSXS.x`（`.x` 可能是 `.5` 到 `.12` 中的任意一个，看你 PR 版本；不确定就把存在的都改一遍）。
3. 若没有 `CSXS.x` 这个键，就右键 `Adobe` → 新建 → 项，命名为 `CSXS.x`。
4. 在右侧空白处右键 → 新建 → **字符串值**，名字填 `PlayerDebugMode`，数值填 `1`。
5. 关闭注册表编辑器。这一步让 PR 允许加载未签名的扩展。

**第二步：复制扩展文件夹**

1. 完全关闭 Premiere Pro。
2. 把本项目里的 `com.delivery.multiexport` 整个文件夹，复制到：
   ```
   C:\Users\你的用户名\AppData\Roaming\Adobe\CEP\extensions\
   ```
   （`AppData` 是隐藏文件夹，资源管理器地址栏直接粘贴 `%APPDATA%\Adobe\CEP\extensions` 回车即可到达。）

**第三步：在 PR 里打开**

1. 启动 Premiere Pro。
2. 菜单「窗口」→「扩展」→「多版本导出」。
3. 面板会出现在右侧，拖到顺手的位置即可。

> 建议在 PR 里先建好两个导出预设（有字幕版 / 无字幕版），这样面板里的「导出预设」下拉能直接扫到并选中。预设放在 AME 的预设目录（`文档\Adobe\Adobe Media Encoder\<版本>\Presets\`）。

## 使用

1. **选序列**：勾选要导出的序列（可多选）；纯数字命名的序列（如 `1`、`12`）会自动勾上。
2. **配版本**：每个版本卡片里选预设、定音轨模式、填输出目录（或点「浏览…」）。
   - 版本卡片前的「启用」复选框决定它是否参与本次导出：只勾一个 = 单独导出该版本；全勾 = 全部导出；任意组合。
   - 成片类：音轨模式选「不静音」。
   - 去音乐类：选「静音非保留轨」，并在下方勾选要保留的人声轨（如 A1、A2）。
   - 想加新交付版本，点「＋添加版本」。
3. 点「一键导出」。导出中顶部有进度条，显示百分比、当前状态、已用时间、预计剩余时间；可随时点「停止」。

所有版本配置（名称/预设/音轨/目录）会自动记住，重开面板不丢。

## 产物

每个版本各自输出到独立目录，文件名保持序列名：

```
版本A的目录\序列名.mp4
版本B的目录\序列名.mp4
```

若多个版本填了同一个目录，会自动给文件名加 `_版本名` 后缀，避免互相覆盖。

输出后缀（`.mp4` / `.mov` / `.mxf`…）由各版本所选导出预设的 `ExporterFileType` 自动推断，不需要手动填格式。

## 关键实现说明

- **静音 API**：`Track.setMute(1/0)` 是 Premiere 原生 ExtendScript API（成功返回 0），无第三方依赖。
- **导出 API**：`Sequence.exportAsMediaDirect(outputPath, presetPath, exportType)`，提交到 AME 渲染队列。
- **目录浏览**：改用 Windows 现代文件对话框（`IFileDialog` 的 `SetFolder`），能精确定位到上次选择的目录；绕开了老式 `FolderBrowserDialog` 那个「起始目录只第一次生效」的 Win7 老 bug。
- **防竞态**：每个版本串行导出，等输出文件完整落地（大小稳定 2 秒）后再做下一个；「去音乐」版本导出前静音、导出后立即恢复，避免时序冲突。
- **容错**：导出中途出错或停止，会自动恢复所有音频轨静音。
- **配置持久化**：版本列表存 `localStorage`，重开面板不丢。
- **停止语义**：停止是"软停止"，只能让当前这一条跑完后不再开始下一条，无法中断 AME 里正在渲染的任务（Premiere 脚本能力限制）。

## 目录结构

```
com.delivery.multiexport/
├── CSXS/manifest.xml        # 扩展清单（PPRO 14.0 / CSXS 7.0）
├── index.html               # 面板 UI
├── js/CSInterface.js        # CEP 桥接库
├── js/main.js               # 编排逻辑（版本列表、批量、进度、停止、目录浏览）
└── jsx/
    ├── host.jsx             # 宿主脚本（PR 内执行：序列/音轨/导出）
    └── folderpicker.ps1     # 目录选择对话框（IFileDialog 封装）
```

## 版本历史

- **v3.2.0**：修进度条不显示的 CSS bug；界面重构（分组卡片、预设+音轨两列并排、音轨列表多列流式）；目录浏览换成现代 `IFileDialog`，解决起始目录定位不生效的问题；移除调试日志。
- **v3.1.3**：浏览目录定位优先级改为「上次选的位置 > 当前输入框路径」，选完成片后点其他版本也能直接定位到刚选的路径。
- **v3.1.2**：修浏览选目录后不回写版本数据导致的“输出目录不存在”及位置不记忆。
- **v3.1.1**：修预设自动选中不回写数据导致“导出预设无效”；浏览目录记住上次位置。
- **v3.1.0**：每版本卡片加「启用」复选框，只勾选的部分才参与导出，支持单独导出某个版本。
- **v3.0.0**：把写死的三版本改为可增删的「版本列表」，每个版本独立配置预设/音轨/目录；配置持久化到 localStorage。
- **v2.2.0**：修「恢复音轨失败」误报；修无音乐版静音所有轨道的回归；纯数字序列默认选中；加进度条与时间估算；加停止按钮。
- **v2.1.0**：修中文路径乱码；三版本独立输出目录。
- **v2.0.0**：批量多选序列；按列表勾选音轨；自动推断输出后缀。
- **v1.0.0**：首版，单序列三版本导出。
